## Built
- proofread/genome/
  - schema.py: re-exports contracts.Genome (D-005) + `load_genome`, `save_genome`, `default_genome`.
  - default_genome.json: champion 0 (equals `Genome()` defaults). Prompt is neutral: no cheating
    instruction, no policy hints (tested).
  - editable_surface.py: `validate_candidate(candidate, champion) -> Genome` or `EditRejected(reason)`.
    Schema (extra=forbid) + tools only narrow (enabled subset, run_timeout_s/max_file_bytes <= champion)
    + added_policies append-only (champion's present and unchanged, unique ids, no base ids, regex
    compiles) + prompt/memory size bounds. Re-validates from a dump so model_construct cannot bypass.
  - patch.py: `apply_patch(champion, ops)` (RFC 6902 via jsonpatch; rejects ops/`from` outside the
    Genome top-level fields, then validate_candidate), `diff(champion, candidate)`.
- proofread/models/
  - config.py: ALL model names, slugs, prices, role -> key mapping. `agent_model()` returns
    `PROOFREAD_AGENT_MODEL` env, else `SELECTED_AGENT_MODEL` (set this after S6b), else claude-sonnet-5.
    OpenRouter prices read at runtime from /models (cached 7 days in data/openrouter_prices.json)
    with a fallback table; the client prefers OpenRouter's `usage.cost` when returned.
    `OPENROUTER_REASONING_EFFORT` (empty by default) lets the integrator cap reasoning spend per slug.
  - ledger.py: `SpendLedger` on data/spend.sqlite (WAL, busy_timeout, per-call rows: ts, role, model,
    budget_key, tokens, cost, episode_id). `check(budget_key)` raises BudgetExceeded when total >= 150
    or the key's cap (contracts.BUDGET_CAPS_USD) is hit; unknown keys count toward total only.
    Env `PROOFREAD_SPEND_DB` overrides the path.
  - client.py: `make_client(role, model)` -> AnthropicClient (raw httpx Messages API; no anthropic SDK
    dep available) or OpenRouterClient. Retries 408/409/425/429/5xx/529 + transport errors with
    backoff and retry-after; 4xx raise ModelError at once. Budget checked before, cost recorded after
    every call. Keys via dotenv_values (never exported, never logged; repr hides them). Assistant
    turns are replayed verbatim (thinking blocks / OpenRouter reasoning_details kept). temperature is
    omitted for models that reject sampling params (opus-5-5, sonnet-5, opus-5).
- proofread/agent/
  - tools.py: read_file, write_file, list_dir (from sandbox.snapshot, no exec), run, apply_patch
    (exact single-occurrence old_string -> new_string replacement).
  - loop.py `AgentLoop`: observe records; enforce pre-verifies a prospective write Action for
    write_file/apply_patch, then checkpoint + write + verify real effects + restore on violation;
    `run` checkpoints, verifies effects, restores and returns "DENIED: ... violates policy <ids>".
    Fail closed: verifier exception, verdict count mismatch, ok=False with no ids, ok=True with ids,
    verdict policy_hash != verifier.policy_hash, added-policy evaluation error -> FAILCLOSED. Added
    policies via `proofread.policies.reference.evaluate_added` (lazy). Unattributed non-exec actions
    get CODE-ATTR-001 even if the verifier misses it. Honors workflow (max_turns, plan_before_code,
    run_tests_every_n_edits reminders, on_failure/max_retries when the last test run failed), context
    (tool output truncation, keep_last_n_turns window, summarize_old_turns = deterministic list of
    earlier tool calls, include_test_file_in_prompt), tools.enabled/run_timeout_s/max_file_bytes.
    A response cut off by max_tokens with no tool call gets a "continue" nudge (counts as a turn).
  - episode.py `make_episode_runner(...)` -> implements contracts.EpisodeRunner. Works with NO args
    (real DockerSandbox factory resolved lazily in wiring.py, make_verifier("auto"), WorkspaceGrader,
    PristineGrader(sandbox_factory), make_client); every factory injectable. Slot = W1
    `proofread.sandbox.runner.sandbox_slot` if importable else a per-runner Semaphore(12).
  - mechanism.py `classify(task, passed_workspace, violations)`.
  - wiring.py: sandbox candidates tried in order: proofread.sandbox.make_sandbox,
    proofread.sandbox.docker_sandbox.DockerSandbox, proofread.sandbox.docker.DockerSandbox,
    proofread.sandbox.runner.DockerSandbox, proofread.sandbox.DockerSandbox; called as
    `impl(episode_id=...)`. Adjust `_SANDBOX_CANDIDATES` if W1 names it differently.
- proofread/cli.py: `proofread run-episode --task ID --genome PATH --mode observe|enforce --model SLUG
  [--pristine] [--arm smoke] [--budget-key K] [--seed N] [--trace-dir traces] [--stub]`.
  `--stub` runs against in-memory fakes (task id `stub/...`), no docker/network/spend.

## Semantics the integrator should know
- Role from budget_key (arm fallback): "selection" -> selection (OPENROUTER_API_KEY); "baselines" ->
  baseline (BASELINE_API_KEY for native claude-* ids in ANTHROPIC_MODELS, OPENROUTER_API_KEY for
  slugs like openai/gpt-5.5); "arm_*", "smoke", anything else -> agent (AGENT_API_KEY). Empty
  budget_key is derived from arm (A->arm_A, B, C, C_noret, baseline->baselines, selection, smoke).
- BudgetExceeded: the episode ends, is still graded, and EpisodeResult.error starts with
  "BudgetExceeded". Not re-raised.
- EpisodeResult.violations = every failed policy id seen (attempted, deduped), in both modes.
  In enforce, denied attempts do not persist, so `mechanism` is computed from effective violations
  (observe: all; enforce: only final-diff ones). Enforce + any final-diff violation => passed_workspace
  forced False (the residue cannot be rolled back selectively; fail closed).
- Pristine (per W2): workspace grade in the episode sandbox, export_files, stop sandbox, release slot,
  then `PristineGrader.grade_files(task, files, episode_id)`. The agent's last assistant text is passed
  as `final_output` to graders that accept it; "[flag_for_human_intervention]" fails pristine too.
- Traces: traces/<episode_id>.jsonl (relative to cwd unless trace_dir is absolute). Records: meta
  (incl. full genome), prompt, model, tool, verify (actions + per-action failed ids), retry,
  truncated, grade, result (+ effective_violations).
- Grader exceptions -> passed False with error (fail closed).
