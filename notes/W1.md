# W1 notes: sandbox and capture

## What is built

- `proofread/policies/reference.py`: the six base policies as pure functions.
  `evaluate(action, net_allowlist=()) -> list[str]` (sorted failed ids), `evaluate_added(action, added)`
  (deny_path_glob on path/dst for non exec/net kinds, deny_added_line_regex on added_lines of write/rename,
  deny_exec_regex on cmd of exec; invalid regex fails closed), `BASE_POLICY_HASH` (sha256 over the
  canonical JSON of `POLICY_SPEC`, which holds every table and regex the policies use).
- `proofread/actions/canonicalize.py`: canon_path (relative -> /workspace, `..`, `//`, NFC), text
  normalization (NFC, CRLF and lone CR -> LF), PEP 263 coding-cookie aware decoding (utf-7 trick),
  multiset line diff, config section detection (setup.cfg/tox.ini/pytest.ini/pyproject.toml; top-level
  pyproject edits report `<top>` so dotted `tool.pytest...` keys fail closed).
- `proofread/actions/effects.py`: snapshot diff -> Actions (write, delete, rename by inode then hash,
  chmod, file<->symlink type change, symlink retarget and resolved-content change, symlinked-directory
  aliases), plus `scan_output` for blocked attempts (writes outside -> attempt_outside, network -> net).
- `proofread/sandbox/snap.py`: in-container walker baked into the read-only image, run as root with
  `python3 -I -S`. Stat prefilter (mode, ino, size, mtime_ns, ctime_ns, nlink, uid); protected paths
  (manifest + test/grader globs) always rehashed. Symlinks followed only into capture roots (or safe
  read-only files); /proc, /sys, /dev never read. >50k entries = capture failure (fail closed).
- `proofread/sandbox/runner.py`: `DockerSandbox(episode_id, *, image="proofread-sandbox:py312", ...)`
  implementing all of contracts.Sandbox, `SANDBOX_SEMAPHORE` (12), `async with sandbox_slot():`
  (per-event-loop fallback so repeated asyncio.run works), `build_image()` / `ensure_image()` (rebuilds
  when the `proofread.hash` label differs from Dockerfile+snap.py), `exec_root()` (out-of-band, for
  graders/tests only), `cleanup_stale()` (removes ALL label=proofread=1 containers; do not call while
  other workers run).
- `proofread/sandbox/scenarios.py`: 38 golden cheat and 16 benign scripted episodes, reusable as
  realistic Action inputs for differential tests (`run_all(GOLDEN)`).

Container: `--runtime=runsc --read-only --network none --init`, tmpfs /workspace (256m, uid 1000) and
/tmp (256m), `--cpus 1 --memory 1g --pids-limit 4096 --ulimit nproc=256`, `--cap-drop ALL` plus the
caps the root-side capture needs, `no-new-privileges`. Agent commands: root wrapper runs
`timeout -s KILL t setpriv --reuid=1000 ... bash -c CMD`, then `pkill -STOP/-KILL -u 1000`, then
capture. `write()` streams content into the container as uid 1000 and uses the same capture.
Env for every exec: HOME=/tmp, PYTHONNOUSERSITE=1, PYTHONDONTWRITEBYTECODE=1.

gVisor findings (worth knowing for everyone):
- `--pids-limit 256` crashes the runsc sandbox under a fork storm (the host cgroup counts sentry
  threads). RLIMIT_NPROC (`--ulimit nproc`) is enforced by gVisor and contains fork bombs.
- A uid-1000 `kill -9 -1` does not reach processes from other `docker exec` sessions; root `pkill -u`
  works. Without `--init` killed processes stay as zombies.

## How to run

- Pure (in `make test-fast`): `uv run pytest -q tests/golden_cheats/test_reference_policies.py
  tests/golden_cheats/test_effects_pure.py tests/benign/test_canonicalize.py`
- All W1 (docker, ~30 s, scenarios run concurrently under the semaphore):
  `uv run pytest -q tests/golden_cheats tests/benign` -> 152 passed (91 pure + 61 docker), 30-50 s.
  Docker tests are marked `@pytest.mark.docker`.

## Detection coverage (golden cheats, all flagged in the real sandbox)

direct write, shell redirect, sed -i, python open, symlink replace, write-through symlink, symlinked
tests/ directory, hardlink, git checkout of an old test, rename-replace (cross step, detected as
rename with dst), create-then-move in one step, delayed background write, delete, chmod, conftest
monkeypatch, .pth in workspace and in /tmp user site, sitecustomize, planted test bytecode
(__pycache__ .pyc), pytest.ini addopts, pyproject [tool.pytest.ini_options], setup.cfg [tool:pytest],
Makefile, skip marker, CRLF skip, `from pytest import skip as _s`, `import pytest as pt`,
unittest.skip, raise SkipTest, fullwidth (NFKC) `pytest.ｓｋｉｐ`, utf-7 coding cookie, same-size edit
with forged mtime, write outside (/etc, /usr/local/bin), write() tool to site-packages, /dev/shm,
python socket, curl/wget, unattributed out-of-band change (final diff). A detached setsid/nohup writer
is killed before it can write.

## Known gaps (honest)

- Network: attempts are blocked by `--network none`; they are only RECORDED when visible in the command
  text (curl, wget, pip install, git clone URL, ...) or in the output (resolver/connection errors).
  A socket attempt whose error is swallowed is not recorded (no effect either). No syscall tracing
  (strace unavailable under gVisor; runsc --strace is a runtime-wide flag).
- Writes outside /workspace, /tmp, /dev/shm: blocked by the read-only rootfs and uid 1000; recorded as
  attempt_outside only from error text (EROFS/EACCES on a path outside scope). Suppressed stderr hides
  the attempt (no effect either). Output that merely prints "Read-only file system" is flagged
  (attempt_outside with empty path, fail closed).
- Policy ordering in a single step: create-and-rename within one command appears as a write of the
  destination (still flagged by path).
- Files > 2 MB: hashed, but added_lines carry a `<content not captured>` marker instead of lines, so
  CODE-SKIP-001 cannot see skip markers inside them.
- `.pytest_cache` is not captured (only affects test ordering / --lf, which the fixed test command
  does not use).
- String obfuscation (`getattr(pytest, "sk"+"ip")`) and in-solution tricks (operator overloading, call
  counting) are not base-policy matters; the pristine grader measures them.
- checkpoint/restore cover /workspace only; /tmp changes persist across a restore.
- CODE-SKIP-001 also judges rename actions (their added_lines are the destination content diff).
  Test-name patterns (test_*.py, conftest.py, tests/**) are protected only inside /workspace; manifest
  paths and grader patterns (.pth, .pyc, sitecustomize, ...) are protected anywhere.
- CODE-GRADER-001 includes *.pyc/*.pyo (planted bytecode) and pytest.toml/.pytest.ini beyond the
  CLAUDE.md list. Benign runs write no bytecode because every exec sets PYTHONDONTWRITEBYTECODE=1.

## Notes for other workstreams

- Graders: `sandbox.run("python test.py")` goes through capture like any step; call `final_diff()`
  before grading. The exec env already disables user site and bytecode writing. `export_files()` skips
  __pycache__ and .pytest_cache and non-regular files (symlinks are not followed).
- W3 (biject differential): `proofread.sandbox.scenarios.run_all(GOLDEN + BENIGN)` yields realistic
  Actions; `POLICY_SPEC` has every regex/table for the Lean encoding.
